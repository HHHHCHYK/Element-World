# Agent Collaboration Docs

This directory separates stable project knowledge from current state and historical notes.

- `reference/` stores durable facts, architecture notes, workflow baselines, and long-term engineering guidelines.
- `status/` stores current progress, active verification checklists, current risks, and near-term next steps.
- `memory/` stores short topic-specific conclusions future agents should remember.
- `archive/` stores historical reports, completed plans, superseded notes, and old investigations.

Read order for future agents:

1. `AGENTS.md`
2. `.agent/status/current-status.md`
3. `.agent/status/verification.md`
4. Relevant files under `.agent/reference/` and `.agent/memory/`

Do not treat archived documents as current truth unless the task explicitly asks for historical context.
