# 策划目录

这里存放 ElementWorld 的玩法策划、内容设计和发布范围沉淀。

## 当前主题

- 首发核心玩法：单武器元素战斗。
- 设计方向：玩家使用一把元素武器，通过目标状态、怪物特性和环境条件触发元素反应。
- 一级原则：[世界驱动的单武器元素战斗](combat/world-driven-elemental-combat.md)。
- 草反应计划：[草反应实现策划](combat/dendro-reaction-plan.md)。
- 暂不作为首发核心：多武器切换反应、完整生存资源链、世界生成、新怪物大规模扩展。

## 建议文档分类

- `combat/`：元素战斗、反应节奏、武器与附魔。
- `content/`：怪物、掉落、探索目标、可玩内容清单。
- `release/`：首发范围、验收标准、试玩反馈整理。
